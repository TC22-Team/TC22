RRPR Badge at ICIAP 2027

The Reproducible Research in Pattern Recognition (RRPR) Badge, promoted by IAPR TC22, is awarded to accepted ICIAP 2027 papers whose code allows their results to be reproduced.

It follows the process introduced at ICPR 2026. Applying is optional and has no effect on the scientific review of the paper.

How it works

1At submission
  • Tick Apply for the RRPR Badge in the OpenReview submission form.
  • Provide the code in the form: an anonymised repository on anonymous.4open.science (preferred) or an anonymised zip file.
  • No code at submission, no badge: the request is not considered.
2After acceptance
  • Only papers accepted through the regular review are evaluated.
  • Make the code public right away, and in any case before the camera-ready deadline. The anonymous repository can simply be made public.
3Badge review
  • Reviewers check the released code, following the reviewer's guide.
  • The Reproducible Research Chairs decide on the badge.
  • Badged papers are listed on the ICIAP 2027 and TC22 websites.

What the code needs

  • Public source code, ideally under an open-source licence.
  • A README or INSTALL file explaining how to install the dependencies and how to run the code.
  • Publicly available data, including trained weights for neural networks.
  • Everything needed to obtain the results reported in the paper.

During the paper review the code must stay anonymous, and the paper must not link to it.
