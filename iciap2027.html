RRPR Badge at ICIAP 2027

    

After its first edition at ICPR 2026, the Reproducible Research in Pattern Recognition (RRPR) Badge promoted by IAPR TC22 comes to the 24th International Conference on Image Analysis and Processing (ICIAP 2027), Modena, Italy, 13–17 September 2027.

The badge is awarded to papers accepted to the main conference whose code, after a specific review, is considered reproducible. Applying is optional and has no effect on the scientific review of the paper.

Submission and review process

  1. When submitting the paper on OpenReview, authors tick the Apply for the RRPR Badge option and provide the code in the submission form, either as a link to an anonymised repository on anonymous.4open.science (preferred) or as an anonymised zip file. Applications without code at submission time are not considered.
  2. The paper goes through the regular review process. Only accepted papers are evaluated for reproducibility.
  3. Immediately after acceptance, and in any case before the camera-ready deadline, authors make the code publicly available (e.g., on GitHub). The anonymous repository can simply be made public.
  4. The ICIAP Reproducible Research Chairs assign reviewers to each eligible paper.
  5. Each reviewer checks the code and writes a short report with a recommendation, following the reviewer's guide.
  6. The Reproducible Research Chairs act as meta-reviewers and decide on the badge attribution.

The list of badged papers will appear on the websites of ICIAP 2027 and of IAPR TC22.

Code requirements

The code is eligible for the RRPR Badge if:

  • it is associated with a paper accepted at the main ICIAP 2027 conference;
  • the authors ticked the option to apply for the RRPR Badge and provided the code at submission time;
  • the source code is public before the camera-ready deadline;
  • it has a README or INSTALL file explaining in detail how to install the dependencies and the commands to compile and run the code;
  • the required data is publicly available (for neural networks, this includes the trained weights).

During the review of the paper, the code must be anonymous, and the paper itself must not contain links to it. See the ICIAP 2027 Call for Papers for the submission rules.

Deadlines

All deadlines are at 23:59 AoE (Anywhere on Earth).

  • Paper submission (with code): 11 February 2027 (first round), 15 April 2027 (second round)
  • Paper notification: 31 March 2027 (first round), 2 June 2027 (second round)
  • Code publicly available: before the camera-ready deadline, 30 June 2027
  • RRPR Badge reviews and notification: to be announced
